把自己画的黑猫放在这里（PNG，透明背景）
（小人现在是 3D 人偶，在网页右上角 ⚙ 设置 →「我的小人」里捏脸；这里只放猫的图。）

画法约定
- 猫朝右画（朝左时程序会自动水平翻转）
- 脚踩在图片最下边，左右居中
- 大约 5:4（宽:高）；大小随意，程序会按高度缩放（建议高 400～800 像素）

文件名（没画的状态会继续用程序自带的版本）
  cat_walk1.png ~ cat_walk3.png 走路（循环播放）
  cat_sit.png         坐着
  cat_stretch.png     伸懒腰
  cat_rub.png         蹭小人

怎么生效
- 网站（GitHub Pages）：图放进这个文件夹，再把 js/scene/characters.js 里的 USE_FOLDER_IMAGES 改成 true，推送到 GitHub 就会用上（至少要有 cat_walk1.png）。现在文件夹是空的，所以默认不去读，避免控制台报 404。
- 双击打开的本地版：浏览器不让 3D 直接读这里的图，请在 ⚙ 设置 →「黑猫的图片」→ 导入。
